# Как запустить пример

1. Открой проект `C:/UnityProjects/AIBT-PatrolResearch` в Unity 6000.7.0b1.
2. Открой `Assets/PatrolResearch/PatrolResearch.unity` и нажми Play.

Синий патрулирует по голубому прямоугольнику. Когда оранжевый или зелёный попадает в жёлтый
сектор на расстоянии до 5.2 м, синий начинает погоню, над ним появляется «!». Цель сохраняется,
даже когда выходит из сектора. При отрыве больше 9 м синий возвращается к прерванной точке
патруля. Оранжевый специально быстрее, чтобы показать этот переход. Зелёный независимо выбирает
случайные точки; он тоже может стать целью. Если медленная цель не отрывается, погоня продолжается.

На карте нет препятствий: это проверка поведения AIBT, без поиска пути. Для сброса сцены останови
и снова включи Play. Случайный маршрут воспроизводится с одинаковым seed.

## Что можно менять

- Маршрут и стартовые позиции — объекты Patroller / Runner / Wanderer в сцене, поле Route.
- Видимость — Sight Range / Sight Angle у Patroller.
- Скорости и отрыв — Trees/patrol.aibt.json, runner.aibt.json, wander.aibt.json.
  После изменения дерева сохрани его и выполни Prepare Runtime в AIBT Graph, выбрав
  AIBT.PatrolResearch.PatrolCatalog и соответствующий существующий runtime asset. Затем снова Play.
- Дерево патрульного откроется двойным нажатием на patrol.aibt.json. Native-ноды проверяй
  через подготовку runtime и реальный Play; reference preview для них не является проверкой.

## Как это связано с API

Trees описывают приоритеты и параметры. Nodes содержит четыре пользовательские native-ноды.
ResearchActor передаёт факты через typed handles и применяет команды перемещения.
ProductionTreeWorld вызывает эти этапы в правильном порядке. Решение «патруль / погоня / возврат»
принимается деревом. Отдельно включать MCP для игры или обычного Play не нужно.

В Play можно выбрать Patroller и нажать Debug Selected в его графе. CLI-команды runtime hosts
и trace read доступны агентам; CLI сам поднимает Editor bridge. Трасса ограничена по объёму,
поэтому для длинного прогона нужно учитывать droppedCount и complete=false.
