# P2-001 decision matrix

Status: Accepted by independent P2-001 round-5 review on 2026-08-14.

| Concern | Accepted draft | Rejected alternatives | Reason / stop condition |
| --- | --- | --- | --- |
| Node dispatch | Public static callbacks on fieldless partial structs | instance/interface/virtual/delegate/function-pointer/reflection dispatch | Closed Burst switch is deterministic and AOT-safe; stop if the pinned Burst compiler rejects all compliant callbacks. |
| Public kinds | Condition and Action only | public Composite/Decorator | No accepted child-transition ABI exists. |
| Assembly ownership | One generated public metadata shard per node asmdef; explicit consumer-owned CatalogSet facade | implicit global discovery; Runtime-owned consumer registry | Unity generators run per compilation and Runtime cannot reference consumers. |
| Cross-assembly seam | Public reserved `BurstGeneratedRuntimeBridge` with opaque validated batch handshake/request/result, frames, readers, accessors, and contexts; Schedule atomically claims a Runtime-owned shared record and gives the job a non-owning view | IVT; public pointers or native-container ownership; consumer access to Runtime internals; single-request or job-local result state | Every token, phase, range, type, and fingerprint is checked; Runtime owns the batch cursor/metrics/lifetime; the original batch reads the job result after dependency completion; default/forged/duplicate schedule values fail safely. |
| Config/memory codecs | TConfig v1 uses only Bool/UInt32/UInt64 authoring scalars plus U32 `GeneratedHandle` ordinals; memory/payloads use the exact P1 vector/fixed-string/ID list plus registered values and reject every user enum/StringEnum; all codecs are generated fieldwise LE with atomic memory staging | persisted schema expansion; raw CLR struct copy; reflection codec; implicit enum registration; semantic payload ID as handle storage identity | The existing P1 manifest schema has an exact projection only for these config scalars; binding metadata separately owns handle semantics; enum-like data uses a registered one-field primitive wrapper; CLR padding/layout is not persisted and late write failure leaves live memory unchanged. |
| Manifest registry | Exact P1 canonical manifest projection and registry SHA, with bindings kept in AccessLayout | alternate Burst registry hash; silently mapping typed binding IDs to P1 reads/writes/sideEffects | Registry handshake remains identical to compiled-program-v1; binding projection awaits its owned versioned compiler contract. |
| Registered values/payloads | Stable `AibtBurstValue`/`AibtValueField` metadata plus generated nested codecs and shard access helpers | Runtime generic serializers; custom semantic equality hooks; built-ins-only bindings | Keeps custom commands useful while Runtime handles only canonical bytes and opaque readers/writers. |
| Capability model | Stable typed binding IDs and phase-specific contexts | field-name/order identity; one broad mutable context | Makes undeclared, wrong-phase, wrong-scope, and wrong-type access diagnosable. |
| Async ownership | One paired `AsyncOperationHandle<TStart,TCancel>` captures start, cancel, and fault-cancel payload; completion remains separately typed | forgeable OperationId; unrelated start/cancel handles | Required for deterministic tombstone and compensating-cancel semantics. |
| Cancellation matrix | NotApplicable forbids Running/async; AbortOnly allows Running but no async cancel; Command requires Running and at least one paired async binding | inferring cancellation from effect commands; unpaired cancel contracts | Declaration, access fingerprint, analyzer, and Runtime cleanup all express one closed capability relation. |
| Shared scope | Read only in ABI v1 | inventing a reducer contract in P2-001; unconfigured shared writes | `Shared` writes remain `AIBT5007` until a separately accepted reducer ABI. |
| Random | Pack=8/Size=24 mutable Enter/Tick context carries an opaque token plus private PCG state/increment copy; exact domain-separated combiner and published vectors; RandomStream is a hashed node-capability bit | public random state; Unity/global RNG; direct mutation of Runtime stream | Only successful matching completion atomically publishes the context state; rejected/failed/copied-stale contexts publish nothing; re-entry/resume continuity and Restart replay are explicit. |
| Result representation | Private U16 code word at offset 0; low byte is the closed logical enum and high byte is reserved zero; public getters expose the enum and remaining fields at their pinned offsets | compiler-generated byte backing plus unspecified padding; throwing or normalizing undefined enum values | This avoids a pinned Burst `BC0101` return-value defect while keeping a canonical U8-code/U8-zero wire image. Constructors store the low byte without throwing; undefined codes are unusable and bridge boundaries reject them as `InvalidStatus` with no mutation. |
| Toolchain | Analyzer/generator targets Microsoft.CodeAnalysis 4.3-compatible APIs and is loaded by Unity's Roslyn 4.10 host | depending on 4.10-only APIs; changing package minimum here | Package currently declares Unity 6000.0 while acceptance runs on 6000.5.8f1. |
| Versioning | ABI version, node type version, catalog/layout/access fingerprints are independent | silent reinterpretation or fallback | Any mismatch rejects before scheduling; a breaking surface/packing change requires a new ABI decision. |
